\chapter{Supplementary Material}
\label{app:supplementary}
%==============================================================================

Use appendices for material that supports the thesis but would interrupt the
flow of the main text: long derivations, extra plots, code listings, datasheets,
or detailed tables.

Each \texttt{\textbackslash chapter} after \texttt{\textbackslash appendix} is
lettered automatically (Appendix~A, Appendix~B, \ldots).
